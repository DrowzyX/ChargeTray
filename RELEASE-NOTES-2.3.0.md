# ChargeTray 2.3.0 Preview — Consolidated Stability & Device Support

## Исправления по отчётам пользователей
- **Redragon Storm Pro M808-KS / 25A7:FA07:** тип мыши не меняется на клавиатуру из-за комбинированного Windows HID или старого локального профиля.
- **Новый батарейный обработчик Redragon/Areson:** поддержан безопасный GetPower (команда 08 04), только для семейства 25A7:FA07/FA08. Используются FF02:0002 FEATURE=17 и FF01 INPUT=17 на MI_01. Ответ проверяется по Report ID, полям статуса, длине, контрольной сумме и допустимому проценту. У семейства FA07 батарея сообщается шагом 10%; отдельно читается признак зарядки, только если он действительно пришёл. Ожидание ограничено, параллельные зависшие запросы не накапливаются.
- **Важное ограничение:** M808-KS ещё не проверена на реальном оборудовании с новым обработчиком. Известные протоколы 25A7 используются разными моделями и прошивками. Если мышь не отвечает, приложение оставит «Нет данных» и запишет причину в диагностику. Никаких выдуманных 40%.
- **ARDOR Fury / 1D57:FA60:** сохранён безопасный пассивный HID-опрос. Пакеты `030040F30A` и `0300407309` **пока не подтверждены** как проценты. Ложные значения не появятся.
- **Клавиатура 258A:0049:** обнаружение и отчёт о vendor-specific HID-коллекциях остаются; батарейный протокол ещё не проверен.
- **AULA F108 Pro:** показания батареи и обнаружение USB-кабеля остаются раздельными; обнаруженный кабель не является доказательством зарядки от розетки.
- **Windows 11 Fluent Light/Dark:** исправлены прозрачные подписи поверх неправильного цвета карточек, чёрные/белые прямоугольные фоны иконок, кнопок, переключателей, индикаторов, а также неполное обновление вложенных панелей после смены темы. RGB и цветовые пресеты сохранены.
- **Обновления из программы:** поиск GitHub Releases учитывает не только стабильные релизы, но и более новые Preview. Проверяются официальный адрес скачивания, версия, наличие ZIP под Windows x64; проверка SHA256 сохранена.
- **Диагностика:** видны исходный источник, причины неответа HID, журнал последних 36 штатных опросов, Protocol Lab. Никакого фонового USB-сниффинга или записи клавиш.

## Что сохранено
- Трей, Dynamic Island, выбор монитора, RGB/акценты в обеих темах.
- Имена устройств, индивидуальные пороги, закрепление, уведомления, 30-дневная история.
- Windows/Bluetooth/HID, AULA, Razer, Xenta, контроллеры и Windows Battery.
- Локальные настройки, проверка обновлений и возможность автономного запуска.

## Проверка после установки
1. Полностью завершите старый процесс ChargeTray через трей.
2. Распакуйте весь ZIP в отдельную папку, запустите `ChargeTray.exe`.
3. Убедитесь, что диагностика показывает **ChargeTray 2.3.0**.
4. Переключите тёмную/светлую тему и RGB; проверьте все вкладки, особенно «Устройства» и «Оформление».
5. Для Redragon M808-KS (25A7:FA07) закройте OEM-приложение на время проверки, включите 2,4 ГГц, нажмите «Обновить», затем скопируйте расширенную диагностику. Если заряд появится — сравните с настоящим процентом фирменной программы; если не появится — предоставьте строку `Redragon / Areson`.
6. Для ARDOR Fury и клавиатуры 258A:0049 точный процент пока не гарантирован: нужен подтверждённый протокол.

Это **Preview-билд**. GitHub Actions тестирует декодер, классификацию, выбор обновлений и компиляцию Win x64. Проверка реальных устройств и всех визуальных состояний требует запуска на Windows пользователя.
