# ChargeTray 1.4.0 — RGB и диагностика устройств

## Новое
- Выбор любого цветового акцента приложения через палитру Windows (RGB).
- Предустановки: шампань, лазурный, фиолетовый, розовый, бирюзовый, белый.
- Плавная RGB-анимация акцентов панели, полоски и островка с ограниченной перерисовкой.
- Сохранение темы в профиле Windows между запусками.
- Краткая диагностика без повторяющихся ролей USB-ресиверов.
- Расширенный отчёт для разработчика: VID:PID, HID usage, IN/OUT/FEATURE и статус протоколов, без серийных номеров и необработанных путей.
- Ссылка на GitHub Issues из контекстного меню.
- Обновлена справка по неизвестным устройствам.

## Улучшения из 1.3.1
- Фоновое пассивное чтение 1D57:FA60, проверка двух совпадающих HID-пакетов.
- Номер версии в диагностике берётся из сборки, а не из статической строки.

## Совместимость
Проверенные устройства: AULA F108 Pro, Razer Basilisk X HyperSpeed и Bluetooth-наушники Move WLH 500.
Работа с 1D57:FA60 экспериментальная: реальный процент зависит от протокола и прошивки конкретной мыши. Новые устройства не получают выдуманных процентов.

RGB изменяет только интерфейс ChargeTray и не управляет подсветкой подключённой периферии.

## Установка
Скачайте ZIP для Windows x64 из Releases и распакуйте. Автономная сборка не требует отдельной установки .NET.

## Статус
Перед публикацией стабильного релиза требуется проверить сборку и новый HID-отчёт на Windows; проверка на незнакомых моделях не выполнялась.
