# ChargeTray 2.1.2 — исправление карточек и диагностика зарядки AULA

- Исправлено перекрытие названия первой карточки строкой «3 устройства / Проверено» на Windows 11 и высоком DPI. Для заголовка и списка применён двухстрочный TableLayoutPanel.
- В карточке AULA F108 Pro явно указано, что статус зарядки неизвестен, если ресивер отдаёт только процент.
- Для устройства AULA добавлен диагностический отпечаток байтов 4–11 валидированного ответа батареи (контрольная сумма проверяется). Это поможет сравнить два состояния: кабель подключён / кабель отключён.
- В техническом отчёте также отображается, виден ли Windows проводной USB-интерфейс AULA F108Pro (0C45:800A). **Это не является подтверждением зарядки**. USB-зарядка от сетевого адаптера не видна компьютеру.
- Сохранены все RGB-настройки, Dynamic Island, история, профили HID и обработчики заряда предыдущей версии.

## Проверка определения зарядки

1. Подключите клавиатуру только через донгл 2,4 ГГц, без кабеля, и скопируйте подробный отчёт.
2. Подключите зарядный кабель, дождитесь следующего опроса (при необходимости нажмите «Обновить») и вновь скопируйте отчёт.
3. Сравните строки `AULA 2.4 ГГц` и `AULA USB data cable`. Если байты не меняются, протокол подключения зарядки пока не подтверждён. Не требуется отправлять серийные номера или пути устройств.
