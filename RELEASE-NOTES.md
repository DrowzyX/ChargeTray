# ChargeTray 1.2

Самостоятельная portable‑сборка ChargeTray для Windows x64.

- Повторный опрос AULA F108 Pro после временного пропадания ответа.
- До двух минут виден последний сохранённый процент с явной пометкой.
- 31 USB‑идентификатор ресиверов Razer, включая дополнительные варианты Viper, Basilisk, DeathAdder, Naga, Orochi, Cobra и Pro Click.
- Сохранены островок, трей, автозагрузка, уведомления и встроенное чтение Bluetooth, геймпадов и системного аккумулятора.

Распакуйте архив полностью и запустите ChargeTray.exe. Если Windows попросит среду выполнения, установите .NET 10 Desktop Runtime x64.
