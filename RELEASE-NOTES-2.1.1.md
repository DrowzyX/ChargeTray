# ChargeTray 2.1.1 — исправление аварийного завершения

- Исправлена ошибка `System.ObjectDisposedException: Cannot access a disposed object (ContextMenuStrip)` при выборе монитора Dynamic Island.
- Аналогично исправлены меню выбора режима оформления и скорости RGB-анимации.
- Уничтожение временного меню перенесено на следующий цикл UI-очереди WinForms, когда закончится обработка щелчка.
- Сохранены данные устройств, настройки и RGB из версии 2.1.0.
- Автономный Windows 10/11 x64 EXE, .NET отдельно устанавливать не требуется.

**Проверка:** на реальном Windows-компьютере несколько раз переключите монитор, тему оформления и скорость RGB. Это предварительная сборка с исправлением ошибки, найденной в пользовательском тестировании.
