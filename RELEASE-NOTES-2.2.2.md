# ChargeTray 2.2.2 Preview — One-Click Device Diagnostics

## Новое
- Кнопка **«Скопировать полный отчёт совместимости»** в разделе «Диагностика».
- Автоматический журнал до **36 последних опросов** батарейных данных в оперативной памяти. Запоминаются только уже распознанные проценты, тип устройства, источник показания, флаги USB/зарядки и типы ошибок.
- Журнал не сохраняется на диск и очищается при закрытии ChargeTray; не требует отдельной службы.
- Для каждого VID:PID в отчёте показаны HID-коллекции, число vendor-specific интерфейсов, их IN/OUT/FEATURE размеры и безопасные рекомендации по исследованию.
- Специальные подсказки для `25A7:FA07` (Redragon/Areson), `1D57:FA60` (ARDOR/Xenta-like) и `258A:0049` (клавиатура).
- Предыдущая диагностика (VID:PID, MI/COL, типы интерфейсов и результаты проверенных батарейных протоколов) сохранена.
- Сбор новых данных выполняется вместе с штатным опросом — без постоянного USB-сниффинга.

## Как получить отчёт
1. Запустите ChargeTray и оставьте его работать некоторое время, чтобы накопились опросы.
2. Откройте **Device Hub → Диагностика → Скопировать полный отчёт совместимости**.
3. Проверьте текст перед отправкой разработчику.

## Ограничения и приватность
Это **автоматический отчёт совместимости**, а не перехват всего USB-трафика. Программа не читает произвольные HID Input/Feature отчёты неизвестных устройств, не записывает нажатия клавиш, серийные номера, MAC-адреса и пути устройств. Маскирование текста — дополнительная мера, пользователь должен проверить отчёт перед публичной отправкой.

Добавление VID:PID и обнаружение фирменной HID-коллекции **не гарантирует** получение процента батареи. Для некоторых моделей нужен проверенный протокол производителя или отдельный Vendor Bridge адаптер.

Preview — до стабильного выпуска проверить на реальных Windows 10/11, с ARDOR Fury, Redragon M808-KS и неизвестными клавиатурами.
