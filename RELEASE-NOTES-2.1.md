# ChargeTray 2.1.0 — Windows 11 Fluent Edition

## Что нового

- Полностью переработанный **Device Hub** с боковой навигацией и пятью разделами: **Устройства, История, Оформление, Настройки, Диагностика**.
- Более современный интерфейс: карточки, Fluent-подобные кнопки и переключатели, адаптация под DPI, скругление окон и попытка включить системный Mica backdrop на Windows 11.
- **RGB-подсветка сохранена** без изменения старых настроек. Исправлена живая перерисовка видимой панели и Device Hub: цвет меняется плавно без нажатия «Обновить».
- Выбор любых RGB-цветов, шести старых пресетов, системного акцента Windows и скорости полного RGB-цикла **5/9/18 секунд**.
- Тёмная, светлая и автоматическая темы Device Hub (доступность системных эффектов зависит от Windows).
- Dynamic Island: выбор монитора и регулируемый отступ сверху (0–120 px). Прежнее раскрытие при наведении и краткое появление при событиях сохранены.
- Уведомление о подтверждённом начале зарядки, о подключении и об уровне ниже пользовательского порога.
- Проверка обновлений, скачивание ZIP по запросу и **добровольная установка с резервной копией** после проверки SHA-256, предоставленного официальным GitHub Release. Если автоматическая установка недоступна, архив можно распаковать вручную.
- Сохранены переименование, закрепление, история заряда, графики, расширенная HID-диагностика и каталог VID:PID из версии 2.0.

## RGB и настройки

Файл `%LOCALAPPDATA%\\ChargeTray\\accent-v1.txt` сохраняется. Пользовательский цвет, анимация и пресеты не сбрасываются при обновлении. Подсветка относится только к интерфейсу ChargeTray; аппаратными светодиодами клавиатур и мышей программа не управляет.

## Установка

Сборка Windows 10/11 x64 самодостаточная — отдельный .NET Desktop Runtime не нужен. Закройте старый ChargeTray в трее и запустите `ChargeTray.exe` из нового архива. Пользовательские настройки останутся в `%LOCALAPPDATA%\\ChargeTray`.

## Совместимость и ограничения

Поддержка AULA F108 Pro, Razer Basilisk X HyperSpeed и Bluetooth использует прежние обработчики. Неизвестные HID-ресиверы могут определяться без подтверждённого процента. Сам факт обнаружения VID:PID не означает поддержки протокола батареи.

## Статус

Это предварительная сборка. До стабильного релиза требуется пользовательская проверка интерфейса на Windows 10/11, нескольких мониторах, светлой теме, RGB-анимации, автозагрузке и обновлении с откатом.
