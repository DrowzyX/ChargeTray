# ChargeTray 2.0.0 — Device Hub

## Главные изменения

- Новый отдельный интерфейс Device Hub на Windows Forms с тёмным Fluent-подобным оформлением.
- Персональные имена устройств, закрепление карточек и индивидуальные пороги 1–99%.
- Уведомления о подключении и отключении после начального опроса.
- Dynamic Island: выбор монитора, краткое автоматическое раскрытие при событиях, прежние плавные анимации.
- История процентов локально, до 30 дней, с мини-графиками и осторожным прогнозом.
- Проверка GitHub Releases и загрузка официального ZIP по запросу пользователя (установка вручную).
- Экономичный режим отключает RGB-анимацию, а выбранный цвет сохраняется.
- Расширяемая локальная идентификация VID:PID через device-profiles.json, без выдуманного заряда.

## RGB сохранён

Все режимы RGB из 1.4 (выбор цвета, пресеты, плавная RGB-анимация) остаются. Эта функция относится к интерфейсу ChargeTray, а не к физической подсветке периферии.

## Совместимость

AULA F108 Pro, Razer Basilisk X HyperSpeed и Bluetooth сохраняют прежние обработчики. Другие донглы могут определяться без процента. Чтение заряда 1D57:FA60 остаётся экспериментальным. Для новой мыши нужны реальные отчёты протокола, а не только VID:PID.

## Безопасность и приватность

История, имена, пороги и параметры хранятся только в %LOCALAPPDATA%\\ChargeTray. Вне приложения запрашиваются только метаданные GitHub Releases, когда пользователь включает проверки. Самостоятельного запуска скачанных файлов нет.

## Для пользователей

Windows 10/11 x64, автономная сборка: отдельная установка .NET не требуется. После проверки на реальном Windows-компьютере архив следует прикрепить к публичному Release.
