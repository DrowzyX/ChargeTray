# ChargeTray 2.2.3 Preview — Redragon Storm Pro M808-KS

Исправлено определение `25A7:FA07`: вместо клавиатуры устройство распознаётся как беспроводная мышь семейства Redragon/Areson.

Этот VID:PID может использоваться несколькими моделями, поэтому не подменяем его точным названием M808-KS без дополнительного подтверждения модели. Имя можно изменить в Device Hub.

Добавлен тест, который проверяет классификацию именно при ошибочной роли Windows `Keyboard`.

**Важно:** это исправление типа устройства, а не поддержка зарядки. Фирменное ПО Redragon показывает 40%, но ChargeTray ещё не умеет проверенно получать батарею от `25A7:FA07`. В отчёте видна потенциальная 17-байтовая FEATURE-коллекция `FF02:0002`. Неизвестные команды без подтверждённого протокола не отправляются.

Сохраняются существующие возможности 2.2.2, включая автоматический диагностический журнал, Protocol Lab и RGB.

Перед публичным стабильным выпуском требуется проверить обнаружение мыши на реальном Windows-компьютере.
