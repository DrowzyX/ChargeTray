# ChargeTray 2.2.1 — Fluent theme and version fixes

- Исправлено белое поле позади карточек в тёмной теме после переключения оформления: фон внутреннего TableLayoutPanel синхронизируется с выбранной темой.
- Убран лишний вложенный Panel при создании страницы устройств.
- Заголовок окна и подпись в боковой панели теперь берут версию из сборки, вместо зашитого «2.1».
- Убрана устаревшая подпись версии Dynamic Island в настройках.
- Оставлены все функции версии 2.2: Protocol Lab, Multi-Source Battery Engine, локальный Vendor Bridge, цветные RGB-пресеты и ранее поддерживаемые устройства.
- ZIP по-прежнему включает автономную .NET-среду, поэтому размер архива меняется незначительно даже при заметных изменениях кода.

Preview — требуется проверка переключения светлой/тёмной темы на реальном Windows.
