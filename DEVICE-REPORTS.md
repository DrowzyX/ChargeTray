# Новые устройства — предварительная поддержка ChargeTray 1.4

| Устройство / интерфейс | ID | Что добавлено | Процент |
|---|---|---|---|
| Steam Controller Puck | 28DE:1304 | Определение контроллера, одна карточка | Нужен отдельный протокол |
| ROCCAT Vulcan Pro | 1E7D:30F7 | Определение клавиатуры, одна карточка | Проводная клавиатура; батарея может отсутствовать |
| Gaming Keyboard | 258A:0049 | Определение клавиатуры | Нужны точная модель и поддержка HID |
| 2.4G Wireless Device / 2.4G Mouse | 1D57:FA60 | Одна карточка мыши, пассивная попытка чтения Xenta | Если совместимый донгл присылает два корректных отчёта |
| ARDOR GAMING Fury ARDW-FURY3325-BK | Пока неизвестен | Добавлено в документацию, требуется подтверждение VID:PID именно этой мыши | Нужна диагностика |

ВНИМАНИЕ: USB ID 1D57:FA60 используют несколько производителей и моделей. Нельзя автоматически подписывать его как ARDOR Gaming, Attack Shark или любую конкретную модель. Если канал не отдаёт корректные 5-байтовые отчёты, интерфейс покажет «нет данных», не выдуманный процент.

## Как проверить

1. Закрой фирменное ПО мыши, если оно удерживает HID-интерфейс.
2. Запусти ChargeTray из собранного проекта.
3. Выбери **Диагностика и поддержка → Скопировать отчёт для разработчика** и отправь разделы `USB / HID`, `HID коллекции` и `Протоколы батареи`.
4. Для ARDOR Fury нужен полный `VID:PID` именно этого донгла. Надпись `PI: DS2403` на корпусе не является USB VID:PID.

Сборка проекта: `dotnet publish src/ChargeTray.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true`. Для сборки нужен .NET 10 SDK; автономный EXE не требует установленного .NET у пользователя.

Для сборки на GitHub: откройте **Actions → Build ChargeTray (Windows) → Run workflow** либо используйте сборку Pull Request. Скачайте ZIP из Artifacts успешно завершённой сборки.
